# 연출 기법 전체 적용 기록 · 2026-10-16

사용자가 앞서 집계한 모든 후보와 미정 대상의 선정·구현을 승인했다. 기존 21건에 미정 항목 9건을 더해 **13개 선택 모션의 연출 적용 30건과 공통 UI 1건**을 제공한다. 같은 모션에 다른 기법을 쓰면 각각 한 건이며, 호격권의 현현·투사 두 형상은 선택 모션 하나로 센다. 실제 재생 확인 대상은 두 형상을 나눈14개다. 최초1차3건도30건에 포함한다.

새 Canvas 효과는 모두 기본 꺼짐이다. 한글·붓 글자는 설치된 시스템 서체, 퍼프·틀·빛은 절차 도형, 실루엣은 기존 몸 알파를 사용한다. 새 원화·몸 프레임·폰트·소리·유료 생성·본게임 전투 규칙은 추가하지 않았다. 선택형 비교를 제공하는 기록이며 모든 효과의 동시 사용이나 본게임 최종 채택을 뜻하지 않는다.

버튼 눌림은 모션 개수와 별도로 **공통 UI 1건**이다. 재생/일시정지·처음부터·추천 조합 실행 버튼에만0.96배 눌림을 주며 레이아웃·키보드 초점은 유지한다. 감소 모션 환경에서는 변형·전환을 제거한다.

## 미정 대상 선정 이유

- 베타 플래시는 준비가 분명한 철산고·어퍼컷을 골랐다. 파동포는 실제 핵과 방출 빛이 주역이므로 먹빛 집중선만 제공한다.
- 효과 밀도·수명은 권기탄·파동포·호격권의 핵/접촉/조각 구분과 순옥살·초구취호패타의 결정타 직전 장식에 적용한다. 원래 공격 실체·실제 분신·접촉·진단 숫자는 제거하지 않는다.
- 내부 틀은 기존 하강 결정타가 있는 초구무신패참 하나를 골랐다. 매 순간이동이나 다른 필살기에 반복하지 않는다.
- 착지 퍼프는 실제 상승·하강·발 디딤이 있는 도약 날아차기다. 기존 sampleGroundEffects의 착지 사건·발 좌표를 재사용하며 순간이동에는 추가하지 않는다.

## 보존 조건·선택 우선순위

전체 모션 길이·타수·실제 접촉 정의·발 앵커·방향 원화는 보존한다. 최초 박자 대안의 첫 두 접촉만 이미 승인된5/25ms 이동을 유지한다. 새 시각 효과 때문에 모션 시간이나 실제 판정 수명을 늘리지 않는다. 파동포 방향성 소멸은 마지막30ms, 호격권은 마지막 판정 종료 뒤의 잔여만 처리한다.

베타를 선택하면 먹빛 집중선 표시를 대체하고, 내부 틀을 선택하면 기존 배경 충격파 표시를 대체한다. 원래 선택 선호는 보존한다. 이로전을 해제하면 방향성 소멸·경계 발광을 비활성화하고, 샌드백 해제 시 실제 명중 기반 글자·종결·틀을 비활성화한다. 이동 포함 해제·재활성화, 지원하지 않는 동작으로 전환했다 돌아오기, 시간 탐색·일시정지에서도 선택을 복원한다. 미세한 퍼프·기운·십자광의 느낌과 한글·붓 질감의 최종 채택은 사용자 비교 대상이다.

## 구현 책임

- `ComboScreen`: 선택 선호, DOM 입력, 표시 의존, 루프와 종료. `BodySilhouette` 표면을 소유하고 종료 시 해제한다.
- `focus-lines.ts`: 기존 응축 어깨/주먹·기공 장전 위치를 공유하는 집중선·베타 샘플링과 그리기.
- `ki-accents.ts`: 기공 외곽 경로와 단발 광점. `ki-drawing.ts`·기공 그리기 파일이 기존 재질별 수명·방향 마스크를 조합한다. 부유기탄 활성 창은 `ki-sampling.ts`의 공유 값이다.
- `stage-accents.ts`: 접지 퍼프·바닥 흔적·첫 방출 반동의 절대 시각. `dojo-drawing.ts`: 기존 도장과 선택형 깊이층. 접지·카메라의 실제 월드 좌표는 바꾸지 않는다.
- `comic-accents.ts`: 마지막 실제 접촉·기존 종결 구간에 의존하는 글자·틀·실루엣 상태. `body-silhouette.ts`: 현재 몸의 알파에만 검정 합성. 원화 밖 글자는 실제 몸/샌드백 경계를 제외한다.
- `effect-hierarchy.ts`: 두 연타의 결정타 직전 장식 농도. 실제 배우와 판정은 기존 소유 객체에 남긴다.
