동작 · 관절을 지정한 정권

정권은 전체 동작 길이를 맞춰 단계별로 비교 재생합니다. 생성된 프레임의 위치·크기는 개별 보정하지 않아 발 디딤과 외형 변화가 그대로 보입니다. 관절선은 1차 시험에서 전달한 목표입니다. 공식 템플릿 재시험은 관절 좌표가 공개되지 않아 관절 보기를 제공하지 않습니다.
