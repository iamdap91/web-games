# 이끼숲 도마뱀

낱장 동작 없이 현재 지형과 이동·외력에서 네 발의 IK, 몸 높이와 꼬리 스프링을 계산하는 독립 시안이다. 그림과 숲은 코드로 직접 그린다.

- 자동 산책 또는 ← → / A D로 이동한다. R은 급회전, Space는 밀기, P는 일시정지다. 화면 버튼으로 같은 행동과 ¼속도·관절 표시를 선택한다.
- 빈 곳을 클릭해 돌을 놓고, 돌을 드래그해 위치·높이를 바꾼다. 선택한 돌은 Delete로 지운다. 최대 8개, 높이 44칸이다.
- `creature.ts`가 시간·지형·발 디딤·IK·스프링을 소유하고 `drawing.ts`는 전달받은 자세를 480×260 격자에 그린다. `index.ts`가 입력과 DPR·루프·화면 수명을 연결한다.
- `?embed=1`은 라이브러리 상세 안에서 사용한다. 화면 종료 시 실행 루프·입력·ResizeObserver·포인터 캡처를 정리한다.

썸네일은 실제 모델을 3.08초 진행시킨 렌더다. Git 제외 `public/assets/maplestory/animation-lab/procedural-creature/preview.png`에 보관하며 경로·해시·규격은 manifest에 기록한다. 외부 이미지나 유료 생성은 사용하지 않았다.

`npm run check`, `npm run build`, 모델 테스트 5개를 통과했다. 실제 Chrome에서 진행·정지·밀림·키 이동·돌 생성/드래그/삭제·영역 밖 포인터 캡처·touchCancel·DPR 2·390px 화면·임베드 종료 후 동결을 확인했다. 모바일 확인은 브라우저 에뮬레이션이다.

정밀 충돌 물리나 래그돌이 아닌 지형 높이를 따라가는 보행 실험이며 본게임의 전투·진행·저장에는 연결하지 않는다.
