# 단면 운반 마당

스프라이트 스태킹 실험. 외부 이미지·3D 모델·라이브러리 없이, `slices.ts`에서 수레를 수평으로 자른 픽셀 단면 27장을 생성한다. 바퀴·적재함·세 상자의 높이별 단면은 독립적인 투명 이미지로 렌더링된다.

- 뷰어: `/src/resources/animation-lab/sprite-stacking/`
- 라이브러리 임베드: 같은 주소에 `?embed=1`
- 라이브러리 자산 ID: `local/sprite-stacking-lab`
- 단면 크기: 38×28px, 27장, 투명 팔레트 인덱스 배열
- PNG 내려받기: 6열×5행, 228×140px. 마지막 세 칸은 비어 있다.
- JSON 내려받기: `width`, `depth`, `palette`, `layers` 포함. 각 층은 행 우선 팔레트 번호 1,064개이며 0은 투명이다.

## 조작

↑↓ / W·S 전후 이동, ←→ / A·D 회전. 마당을 누르고 있으면 그 방향으로 이동한다. 화면 방향키는 포인터 캡처를 지원한다. 오른쪽 구역에서 자동 하역, 왼쪽 구역에서 재적재한다.

자동 회전은 수레의 표시 방향만 돌리는 비교 기능이다. 단면 간격을 벌리면 27장의 실제 단면이 드러난다. 평면 비교는 같은 단면을 높이 없이 한 장으로 합친다. 높이별 단면은 오른쪽 패널에서 선택하며 PNG와 JSON을 내려받을 수 있다.

## 책임과 한계

`CartYard`는 이동·운반·경사 반응 상태를 소유하며 DOM·Canvas에 의존하지 않는다. `YardView`는 수평 이미지를 기울어진 축으로 투영한다. 기본 간격에서 단면 사이에 얇은 틈이 생기지 않도록 각 층을 한 픽셀 두께로 내려 그린다.

회전과 경사는 연속값이며 최종 화면은 nearest-neighbor 픽셀 이미지다. 임의 각도에서는 픽셀 계단이 달라진다. 바퀴 회전, 물리 충돌, 짐 흔들림을 구현한 운전 시뮬레이션이 아니라 단면 표현 비교용이다. 좁은 화면은 데스크톱 Chrome의 뷰포트 에뮬레이션으로 검증했다.

루프·이벤트·ResizeObserver는 `pagehide` 및 `resource-scene-dispose`에서 정리한다.
