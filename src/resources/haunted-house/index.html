반복되는 복도의 재료들

낡은 저택을 위한 공간, 일상 소품, 작은 단서와 유령. 게임에 배치하기 전 원본을 비교하는 리소스 모음입니다.

전체 리소스 공간 소품 조명·단서 위협 효과음
원본 색상이며 카드마다 표시 배율은 다릅니다. 개폐 철문은 닫힘·열림을 나란히 표시합니다. 이미지 모션은 프레임을 펼쳐 비교하며 자동 재생하지 않습니다. 효과음은 재생 버튼으로 들어보세요. 기본 음량은 35%입니다.

리소스 목록을 불러오는 중입니다.

출처: 메이플스토리 월드 리소스 검색. 이미지와 효과음은 저장된 로컬 파일을 사용합니다. 이미지가 보이지 않으면 manifest의 localPath에 파일이 있는지 확인해주세요.

이름은 프로젝트 표시명이며 완성된 맵이나 동일 맵의 세트를 뜻하지 않습니다.
