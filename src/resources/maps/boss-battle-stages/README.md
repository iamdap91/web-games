# 산길·서리숲·잿불협곡·대숲 · 전투맵 8종

리소스 라이브러리 **맵·마을 → 마을 스타일 실험**에서 네 지역의 기존 전투맵 A와 추가 전투맵 B를 나란히 비교한다. 지역마다 한 행에 두 카드를 배치해 총 여덟 전장을 보여준다. `?embed=1`과 독립 화면을 함께 제공한다. 각 카드에는 실제 보스전의 아타호·연묵·비월과 해당 보스를 같은 크기·진형으로 표시하며, 아래 링크는 선택한 지도에서 실제 전투를 새 화면으로 연다.

## 구성

- `index.ts`는 실제 `boar-turn-battle/BattleRenderer` 여덟 개를 생성하고 `mapVariant`를 `original` 또는 `alternate`로 전달한다. `TurnBattle`의 초기 snapshot을 대기 표시로만 사용하고 전투 진행·입력·피해 계산을 복제하지 않는다.
- 지역명·설명과 배경은 실제 보스전의 `battle-map.ts`에 있는 `battleMapDefinition(id, variant)`와 공유한다. 산길의 철갑 멧돼지, 서리숲의 서리갈기 곰왕, 잿불협곡의 불씨심장 아르마딜로, 대숲의 대나무칼 사마귀를 비교한다. 실제 보스전 링크는 `?boss=...&map=original|alternate`를 사용한다.
- 배경과 앞쪽 가림은 Three.js로 제작한 전투맵의 프리렌더를 사용하고, 그 사이에 기존 인물·보스와 움직이는 장식을 합성한다. 갤러리 전용 배경 그림은 만들지 않는다.
- 상단의 움직임 멈춤은 여덟 카드의 그리기를 함께 멈춘다. 멈춘 동안 화면 크기가 달라지면 현재 그림의 CSS 크기만 바꾸어 포즈를 유지하며, 재개 뒤 실제 렌더 크기를 갱신한다.
- 각 지역 제목 옆에는 솔바람 옛짐길·백서리 순례길·잿불 운반로·바람대숲 샛길을 직접 여는 링크가 있다. 이동맵은 **맵·마을 → 지역 이동맵**의 개별 항목으로도 열 수 있다.
- 초기 로딩은 키보드 포커스를 가져오지 않는다. `registerEmbeddedScene`과 `pagehide` 종료에서 RAF·ResizeObserver·이벤트·여덟 렌더러를 정리하고, 늦게 끝난 이미지 로딩으로 화면을 다시 열지 않는다.

`window.bossBattleStages`는 읽기 전용 `ready`, `paused`, `disposed`, `diagnostics`를 제공한다. diagnostics에는 카드별 지역·지도 variant·준비·실패·렌더 횟수와 Canvas 실제 크기가 있다. 화면 밖에서 전투 상태를 바꾸는 API는 제공하지 않는다.

## 범위

새 그림 생성·외부 모델·음향·새 전투 규칙은 추가하지 않는다. 실제 전투 플레이는 각 카드의 보스전 링크에서 확인한다. 대표 이미지 `preview.jpg`는 실제 갤러리를 렌더한 화면을 사용한다.

`나란히 비교`와 `인게임 크기`를 전환한다. 두 모드 모두 실제 보스전의 `BattleRenderer`·16:10 비율을 사용하며 인물과 배경 비율도 같다. 인게임 크기는 논리 화면1100×687.5px을 기준으로 크게 표시하고 좁은 화면에서는 맞춘다. 이동맵 A/B 링크에서 같은 지역의 두 이동길을 고른다.
