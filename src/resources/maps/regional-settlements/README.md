# 네 지역의 생활 마을

솔바람·백서리·잿불·바람대숲의 탐험길과 짝이 되는 독립 보행 마을 시안이다. 기존 해풍나루·눈솔온천마을은 그대로 두고, 네 지역의 건축·생업·주거 골목을 새로 구성했다.

| 지역     | 마을     | 생활 중심                                     |
| -------- | -------- | --------------------------------------------- |
| 솔바람   | 방앗골   | 곡식 방앗간, 목재 보급소, 우물마당, 들밥 부엌 |
| 백서리   | 눈솔마을 | 산장 여관, 겨울 보급소, 공동화덕, 온천        |
| 잿불     | 석공마을 | 대장간, 석공 작업장, 돌조각 광장, 돌집 골목   |
| 바람대숲 | 차향마을 | 차방, 죽세공방, 약초보급소, 바람종 쉼터       |

## 둘러보기

`?region=boar|bear|armadillo|mantis&view=game|overview`로 선택한다. 리소스 라이브러리의 **지역 마을**에도 각각 등록했다.

- 방향키/WASD로 걷거나 열린 마당을 클릭한다.
- 시설 이름을 누르면 건물·주민·생활 시설을 피해 해당 위치까지 걸어간다.
- 가까이에서 Space 또는 살펴보기 버튼으로 시설과 생활 흔적을 확인한다.
- 남쪽 출구를 살펴보면 해당 지역의 넓은 탐험길로 나갈 수 있다. 탐험길에서도 마을로 돌아오는 링크를 제공한다.
- 인게임 시야는 탐험맵과 같은 16:10 화면·인물 배율이며, 전체 보기는 건물과 골목 배치를 확인하는 용도다. 인게임에서는 아타호를 가리는 앞 건물만 옅게 표시한다.

## 표현과 소유권

아타호는 `ai/ataho-v2`의 8방향 대기·보행만 사용한다. 주민은 기존 `village-resource-pack` 정면 그림, 생활 소품은 `MapSpriteResources`의 승인된 로컬 그림을 재사용한다. 신규 생성 서비스 호출은 하지 않았다.

곡면 처마·손칠 표면의 입체 건축과 유기적인 소나무/대나무/정원석을 픽셀 그림과 조합한다. 실제 프리렌더 배경이나 촬영된 스톱모션은 아니며, 기존 이동맵의 실시간 디오라마 렌더러를 공유한다. 12박자 표식 표현과 연속 보행·카메라를 유지한다.

`SettlementGround`가 열린 마당·건물·주민·고정 소품의 보행 경계를 소유한다. 표시용 길 거리장과 실제 걸을 수 있는 마당은 구분한다. `TrailVisit`가 이동과 방문 상태, `SettlementDressing`이 픽셀 소품·주민의 로딩과 GPU 수명, 화면이 입력·루프·종료를 담당한다. 공통 `TrailScene`은 마을의 건축/장식을 주입받아 동일한 캐릭터 합성과 시야를 제공한다.

시설 설명과 방문 기록은 이 화면 안에서만 유지된다. 상점 결제·실내 입장·퀘스트·게임 저장은 연결하지 않았다.
