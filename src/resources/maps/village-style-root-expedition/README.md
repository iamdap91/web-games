# 포자길 답사 · 숲·발견·귀환 조합

이끼 품은 둥지의 굴곡 뿌리·껍질과 이끼 소재·입체 깊이 가림에 원정 지도의 조사 후 연결길 개방을 합친 독립 답사 시안이다. 처음에는 왼쪽 뒤 뿌리가 실제로 끊겨 있다. 화덕에서 넓은 앞길을 돌아 이끼 뒤 쉼터를 발견하고, 포자 씨앗을 조사하면 끊어진 뿌리가 3.2초 동안 자란다. 연출 완료 후 높은 뒤길을 선택해서 입구로 돌아온다.

## 공간과 반응

- `layout.ts`의 동일한 뿌리 곡선·폭·높이가 윗면·6단 둥근 아랫면·보행·인물 발 높이의 기준이다. 끊어진 구간은 윗면과 아랫면에서 실제로 빠져 있고, 연결 뿌리는 별도 geometry다. 표면 normal은 큰 외곽을 대신하지 않는다.
- 최초 클릭 경로는 끊긴 구간을 피해서 오른쪽 앞길을 지나 쉼터로 간다. 발견은 조사와 구분된다. 가까이 와도 씨앗을 사용하기 전까지 연결길은 닫힌다.
- 조사하면 푸른 포자가 켜지고 새 뿌리가 숲 바닥에서 올라온다. 성장하는 동안도 통행은 닫혀 있다. 3.2초 완료 시점부터 키보드 보행과 클릭 경로 탐색이 함께 열린다.
- 쉼터에서 높은 뒤 뿌리를 따라가면 새 연결을 건너 화덕·입구로 귀환할 수 있다. 끊긴 구간 위를 실제로 통과한 후 입구에 도착하면 귀환 반응이 나온다. 입구 버튼으로 순간 복귀한 경우에는 걸어서 귀환한 것으로 기록하지 않는다.
- 입구 재방문은 위치·이동만 초기화한다. 발견·조사·성장 진행·개방·복구·시설 방문·누적 시간·답사 횟수는 현재 페이지 메모리에 남는다. 문서를 새로 불러오면 새 답사로 시작한다.
- 화덕 사용은 12초의 불꽃·부분 조명을, 도장 사용은 지붕 잎 패치·포자 등을 유지한다. 이끼 판은 본체에 고정되어 깊이 순서로 가리지만, 인물 접근 시 폭이 줄어 씨앗과 인물의 위치를 읽을 수 있다.

## 재사용과 소유권

기존 `village-style-mixed-forest`의 렌더·소재 작성 원리를 해당 폴더로 복제한 후 단절/성장 메시, 포자 씨앗, 접근 시 이끼 여백, 조사/통행/귀환 규칙을 구현했다. 원본 시안은 수정하지 않았다. 색만 바꾼 시안이나 iframe 포장은 아니다. 껍질·돌·이끼·버섯의 색/normal 지도는 이 폴더 `materials.ts`의 코드 소재판이다. 높이장 normal 계산만 기존 `village-style-lit2d/normal.ts`의 순수 함수를 재사용한다.

승인된 `ai/tiger-hero` 대기·보행 4방향 36개 원본 RGBA 프레임을 그대로 쓴다. `TrailSprite`의 `frame-pivot` 배치, 원본 비율·아래 pivot·카메라 yaw·수직 인물판·pitch 투영 높이 보정을 유지한다. 새 유료 생성·외부 사진·경제·전투·영구저장·본게임 연결을 추가하지 않았다.

진행과 시간은 `ForestVisit`, GPU·메시와 조명은 `ForestScenery`/`ForestScene`, 입력·버튼·포커스·정지·종료는 `ForestScreen`이 소유한다. 화면을 누르기 전에는 포커스를 가져가지 않는다. 정지 중 시간·성장·애니메이션은 멈추고 크기 변화가 있을 때 마지막 상태를 다시 그린다. `?embed=1`에서도 모든 조작 버튼을 유지한다. `pagehide`/`resource-scene-dispose`는 이벤트·RAF·ResizeObserver·geometry/material/texture/shadow와 WebGL context를 정리한다.

## 조작과 접근 좌표

WASD/방향키 또는 뿌리 윗면 클릭으로 걷는다. Space/시설 사용(쉼터에서는 씨앗 조사), M/전체 조망, R/도장 복구 비교, N/요철, L/불빛, Esc/멈춤, 입구 버튼/재방문을 제공한다.

| 장소             | 좌표 `(x,z)`   | 반응                                |
| ---------------- | -------------- | ----------------------------------- |
| 입구             | `(-9,5)`       | 실제 포자길 귀환 판정 / 재방문 위치 |
| 씨앗 화덕        | `(-5.2,3.6)`   | 불꽃과 온기                         |
| 버섯 도장        | `(-0.3,-0.1)`  | 잎 지붕과 포자 등 복구              |
| 이끼 뒤 쉼터     | `(-4.2,-4.5)`  | 발견 후 Space / 조사로 뿌리 성장    |
| 열린 뒤길 접근점 | `(-6.1,-2.25)` | 높은 뒤 뿌리에서 연결 구간 진입     |
| 새 연결의 중앙   | `(-6.2,-0.6)`  | 개방 완료 후 실제 통행 / 왕복       |

쉼터를 높은 뒤 뿌리의 서쪽 끝으로 옮겼다. 처음에는 넓은 앞길과 동쪽 뿌리를 돌아 줄기 뒤를 따라가야 한다. 쉼터→입구 전체 클릭 경로는 개방 전 33.70, 개방 후 14.30 거리로 약 57.6% 줄어든다. 같은 layout의 높이·geometry·보행·경로 기준을 유지하며 실제 연결 구간을 통과한다. 귀환 때 포자 아치를 통과하면서 앞쪽 화덕과 입구가 다시 보인다. 바닥 껍질은 큰 결과 밝은 색면, 가장자리 이끼는 더 어두운 녹색으로 분리했고 두 소재의 2픽셀 노이즈를 4픽셀 블록과 낮은 랜덤 강도로 완화했다.

읽기 전용 `window.villageStyleRootExpedition`은 `ready`, `snapshot`, `paused`, `overview`, `disposed`, `project({x,z})`, `screenPositions`, `diagnostics`를 제공한다. snapshot은 위치·접지 높이·방향·방문·발견·shortcut 단계·openingProgress·실제 연결길 통과·귀환·답사 횟수를 포함한다. diagnostics는 메시/소재/원본 프레임 정보와 조사·개방 진행·통행·방문 기록을 포함한다. 중첩 상태를 동결하며 외부 변경 API를 제공하지 않는다. project는 Canvas 내부 CSS 좌표이고 screenPositions는 시설 접근점이다.

## 검증

- 규칙 테스트 7개: 최초 우회와 허공/본체 충돌, 발견/조사 분리, 연출 중 통행 금지, 완료 후 키보드/클릭 통행, 개방 왕복과 귀환, 재방문 보존, 정지/0초 갱신과 동결 snapshot.
- `npm run check`, `npm run build`, `node --test tests/village-style-root-expedition.test.mjs`가 통과했다.
- 최초 구현의 실제 Chrome 1200×740/DPR2에서 최초 포커스 미탈취, 키보드→클릭 이동, 화덕→쉼터 발견/조사→3.2초 성장→새 뿌리 통행→입구 귀환→재방문을 확인했다. 누적 48.54 거리, 시설 2/3 방문, 연결길 통과·귀환 완료·답사 2회, 콘솔/예외 오류 0건이었다. 정지 중 snapshot/렌더 고정, 390×620 정지 resize 후 렌더 고정, 종료 후 RAF/렌더 정지를 확인했다. PNG와 상태는 `/private/tmp/root-expedition-*.png`, `/private/tmp/root-expedition-verification.json`에 작성했다. 최종 임베드/라이브러리 등록과 preview 캡처는 통합 담당이 수행한다.

높은 뒤 뿌리의 일부는 실제 줄기 벽에 가려진다. 전체 조망과 포자 안내가 위치 파악을 돕고, 접근 시 이끼만 비켜난다. 저해상도 소재·알파 판의 계단과 작은 화면 가독성은 실제 시안 검토의 한계다. 이번 구현은 로컬 독립 답사이며 본게임 채택은 별도 결정이다.

## 통합 화면 검토 · 2026-10-13

통합 담당의 실제 내장 브라우저에서 키보드와 클릭 보행→화덕→쉼터 발견(조사 전 sealed)→Space 조사→성장 중 정지→개방→새 연결 중앙 실제 통과→걸어서 귀환→재방문을 확인했다. 누적 보행 48.59, shortcutCrossed/returned=true, 재방문 visits=2와 발견·개방·방문 기록 보존을 확인했다. 성장 중 정지 상태와 화면 PNG는 같았고 종료 이벤트 뒤 disposed=true/ready=false였다. 좁은 화면 검사는 데스크톱 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다.

이번 개선의 새 쉼터 위치·포자 아치·소재 대비는 통합 담당의 최종 실제 브라우저 검토를 기다린다. 자동 로직에서는 전체 귀환 경로 거리와 연결길 통과·연출 완료 전 차단을 확인했다.

## 확장 조합 통합 검토 · 2026-10-13

새 쉼터 (-4.2,-4.5)까지 앞길로 돌아 실제 발견하고 씨앗을 조사했다. 성장 초반 정지 중 snapshot이 고정됐고 3.2초 완료 뒤 새 연결을 건넜다. 통과 후 입구 재방문은 returned=false를 유지했으며 다시 실제로 걸어 귀환하면 true였다. 열린 쉼터→입구의 실제 보행 거리는 14.305로 경로 기준 14.30과 일치했다. 390×620 가로 넘침 없음과 종료 disposed=true를 확인했다. 순간 복귀 회귀 테스트를 포함한 전용 8개가 통과했다.

화면 크기 검사는 데스크톱 내장 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다. 대표 이미지는 통합 환경의 실제 렌더이며 PNG 크기·SHA256은 resources/manifest.json에 기록했다.
