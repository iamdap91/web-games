# 온기 도는 도장 · 실내생활·복구 조합

실내생활과 복구를 결합한 독립 리소스 시안. 온빛 도장의 실제 야외 지형과 표면 조명 위에 살아나는 골목의 실내 단면, 개울 골목의 생활 흔적을 결합했다. 도장은 통짜 큐브 대신 벽·문·마루·가구를 입체로 구성했다.

## 답사

1. 입구에서 중앙 계단 위 **도장 문앞**으로 걸어간다. 좌표는 `{ x: 1.2, z: -4.4 }`.
2. Space / 시설 사용 / 도장 복구 / R로 복구한다. 문앞에서만 복구할 수 있다.
3. 가까이 다가가면 지붕과 앞벽만 걷히고 마루·찻상·무기걸이·수련생이 드러난다. 수련 마루는 `{ x: 0.8, z: -7 }`.
4. 마루에서 시설 사용을 하면 6초간 수련생의 팔·다리 동작이 커진다. 동쪽 뒤문을 걸어서 통과해 `{ x: 5, z: -7 }` 빨래마당으로 나온다.
5. 나무 뒤 쉼터 `{ x: 9, z: -9.4 }`를 방문하고 언덕길로 입구에 돌아온다. 입구로 버튼은 복구·방문·시간을 보존한다.

WASD / 방향키, 바닥 클릭 / 터치로 이동한다. 전체 조망, 화덕 빛 옮기기, 표면 요철 비교, 멈춤 버튼은 `?embed=1`에서도 남긴다. 첫 로드에서는 부모 화면의 포커스를 가져오지 않는다.

## 책임과 검증 접근점

- `VillageVisit`: 보행·충돌·복구 조건·방문·수련 반응·뒤문 통과 기록 소유.
- `layout.ts`: 지형 높이와 벽·문·가구 보행 판정 및 복구 상태를 고려한 경로.
- `LivedDojoScene`: 실제 3D 건축·선택적 단면·수련생과 빨래 움직임·원본 아타호 렌더링.
- `LivedDojoScreen`: 입력·DOM·RAF·resize·종료 수명 소유.
- `window.villageStyleLivedDojo`: 읽기 전용 `ready`, `snapshot`, `paused`, `overview`, `disposed`, `project({x,z})`, `screenPositions`, `diagnostics`. `snapshot`의 `interiorOpen`, `training`, `shortcutUsed`와 `diagnostics`의 같은 상태로 반응을 확인한다. project와 screenPositions는 canvas 내부 CSS 픽셀 좌표다.
- 당시 로직 검사: 위치 조건 복구, 복구 전 차단/후 보행, 뒤문 통과 기록, 가구·벽 충돌, 입구 복귀 보존.

## 리소스와 범위

`ai/tiger-hero`의 승인된 원본 RGBA·비율·pivot·4방향 프레임을 기존 TrailSprite로 그대로 재사용한다. 수련생은 32×48 픽셀 인물판을 코드로 직접 그려 발 pivot·nearest·접지 그림자를 맞추고 외부 주민 리소스나 새 유료 생성은 사용하지 않는다. 생활 소품은 이동선 밖에 모았다. 경제·전투·저장·본게임 연결은 없다.

기존 `village-style-mixed-dojo`의 야외·재질 코드에서 독립 복사 후 도장을 새로 구성했다. 원본 시안을 수정하지 않는다. 복구 비교는 되돌리기보다 이 페이지 새로고침으로 한다. 이동 중 pause는 RAF를 멈추고 resize는 멈춤 상태에서도 한 번 재렌더하며, 종료는 observer·입력·RAF·geometry·material·texture·WebGL context를 정리한다.

## 통합 화면 검토 · 2026-10-13

통합 담당의 실제 내장 브라우저에서 문앞 클릭 보행·Space 복구·실내 수련·뒤문 통과·빨래마당·쉼터·화덕의 5/5 방문과 입구 복귀 기록 보존을 확인했다. 정지 중 입력 전후 상태와 화면 PNG가 같았고, 390×620에서도 조작 버튼과 상태를 유지했다. 원본 인물의 발 높이와 비율도 진단으로 확인했다. 좁은 화면 검사는 데스크톱 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다.

## 완성도 개선 · 2026-10-13

바탕 풀·흙과 벽·지붕의 붓질 밀도 및 바탕 normal 강도를 낮추고 큰 명암을 유지했다. 낮은 공방에는 굴뚝, 찻집에는 앞 차양을 달아 넓은 도장 처마와 구분한다. 수련생은 직접 작성한 네 포즈의 픽셀 인물판으로 교체했다. 화덕에서 찻물을 데우면 warmed가 보존되고 수련이 9초로 바뀐다. 실제 수련 완료 뒤 teaReady가 생기며 쉼터 사용 시 찻잔의 김이 커진다. 화덕을 사용하지 않은 수련은 기존 6초를 유지한다. 재방문은 준비 상태를 보존한다. 새 규칙을 포함한 당시 로직 검사 4개 및 check/build 통과. 실제 화면 검토는 아래 통합 결과에 기록한다.

통합 브라우저에서 화덕→문앞 복구→수련→실제 뒤문→쉼터 차의 5/5 장소 방문과 warmed/teaReady/tea, 재방문 보존을 확인했다. 키보드 보행도 확인했다. 실내 가림 검토에서 앞 들보·간판이 인물 얼굴과 겹쳐 단면 앞벽에 포함하고 수련생을 마루 왼쪽으로 옮겼다.

## 확장 조합 통합 검토 · 2026-10-13

화덕에서 찻물을 데우고 문앞 복구→수련→동쪽 뒤문→쉼터 차를 실제로 사용해 5/5 방문과 warmed/teaReady/tea를 확인했다. 재방문은 기록을 보존한다. 최종 단면에서 앞 들보·간판이 숨겨져 인물 얼굴을 가리지 않고 픽셀 수련생과 주인공이 떨어져 보인다. 390×620 정지 resize의 상태·버튼·가로폭 보존과 종료 disposed=true를 확인했다.

화면 크기 검사는 데스크톱 내장 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다. 대표 이미지는 통합 환경의 실제 렌더이며 PNG 크기·SHA256은 resources/manifest.json에 기록했다.
