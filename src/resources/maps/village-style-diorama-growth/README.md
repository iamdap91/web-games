# 자라는 손길 마을 · 기능 전이

고정 시점 디오라마의 돌조각·석회벽·목재·천 재질과 **정적 색/깊이 프리렌더 캐시**를 유지하고, 연결형 건축의 증축에 따른 공간 변화를 이식한 독립 시안이다.

서쪽 공방 북쪽에 별채를 3초 동안 세운다. 공사 중 별채 그룹만 `dynamicScene`에서 원래 캐시 위에 합성하며 공사장 충돌과 마당의 닫힌 문을 유지한다. 완료 시 `DioramaVisit`이 복구를 확정하고, 별채 그룹은 정적 모형으로 이동한다. 색/깊이 캐시 revision을 한 번 바꾸어 새 별채·작업마당·열린 골목 문을 다시 저장한다. 이후 인물·물·불만 프레임마다 갱신한다. 매 프레임 배경을 다시 굽지 않는다.

별채에는 원래 재질 제작 객체를 사용한다. 마당 울타리와 작업대는 보이는 위치에서 충돌하며 남쪽 문에 실제 보행 폭을 둔다. 문을 닫는 비교 전환으로 발 위치가 막히면 입구로 보정한다. 본게임 저장·경제와 연결하지 않는다.

- 클릭/터치: 실제 길을 찾는 보행. WASD/방향키: 화면 기준 직접 보행.
- `공방 별채 증축` / R: 3초 공사. 진행 중 중복 요청 무시. 완성 후 R: 증축 전 비교.
- Space / 시설 사용: 근처 시설. 공방 화덕을 사용하면 불을 지피며 증축도 시작한다.
- M: 고정 카메라 조망, Esc: 멈춤(건축 시간도 정지), 입구로: 증축 상태를 보존한 귀환.
- 별채 중심 `(-8.5, -1.8)`, 골목 문 `(-4.8, -1.3)`, 새 작업마당 `(-4.8, -2.8)`, 마당 작업대 `(-4.8, -3.8)`.

`window.villageStyleDioramaGrowth`는 ready/snapshot/project/screenPositions/paused/disposed/diagnostics를 읽기만 제공한다. `snapshot.growth.progress`가 공사 진행률이고 `diagnostics.constructionDynamic`/`annexInCache`는 별채의 현재 합성 위치다. `backgroundRenders`로 공사 중 배경 캐시 유지와 완료 재굽기를 확인할 수 있다. embed=1에서도 조작 버튼을 유지한다. 승인된 아타호의 원본 RGBA·프레임 비율·방향 프레임을 보존한다.

검증: 빌드/담당 lint/로직 2개(공사장·문·울타리·작업대 충돌, 단계완료, 중복 요청, 마당 실제 이동, 닫힘 끼임 보정). Chrome embed 실행에서 공사 진행 중 `backgroundRenders=1`, 완료 후 `2`, 동적 → 캐시 편입 확인. 클릭으로 새 마당 `(-4.75,-2.75)` 도착, 직접키/Space/멈춤 시간 정지/430px resize/pagehide dispose와 오류 0을 확인했다.

## 라이브러리 통합 검토 · 2026-10-13

공사 중 배경 렌더 1회를 유지하고 완료 뒤 2회로 갱신하며 별채를 캐시에 편입했다. 열린 골목으로 새 마당에 실제 보행했다.

맵·마을에서 “기능 전이”로 검색한 9개 항목과 원래 맵·기능 출처 연결을 확인했다. 상세 안의 실제 키보드 보행 및 항목 전환 후 이전 뷰어의 disposed=true를 확인했다. 대표 PNG의 크기·SHA256은 resources/manifest.json에 기록한다. 좁은 화면 검증은 데스크톱 브라우저 뷰포트·DPR 에뮬레이션이다.
