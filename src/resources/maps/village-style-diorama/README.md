# 손길 마을 · 프리렌더 디오라마

리소스 라이브러리에서 비교하는 독립적인 마을 표현 시안이다. 입구에서 목공 화덕을 지나 돌계단 도장으로 오르고, 동쪽 계단과 북쪽 돌아치 다리를 건너 쉼터에 도착한다. 남쪽 다리와 시장 골목으로 돌아오는 긴 길도 있다. 기존 본게임 진행 상태와 연결하지 않는다.

## 출처와 표현 범위

- [FANTASIAN 제작자 인터뷰](https://blog.playstation.com/2024/09/24/fantasian-neo-dimension-out-december-5-hironobu-sakaguchi-talks-bringing-his-rpg-to-ps5/)의 실물 모형과 사진에 담긴 온기·재질·작은 공간을 시각 참고했다. 이 시안은 실물 사진을 가져오거나 해당 게임의 자체 파이프라인을 복제하지 않는다.
- 환경의 geometry·석회벽·목재·천·돌·흙 CanvasTexture는 이 폴더의 코드로 자체 작성했다. 별도 외부 환경 이미지·모델·새 패키지·유료 생성물을 사용하지 않았다.
- 아타호는 승인된 `ai/tiger-hero`를 기존 `TrailSprite`/`SpriteTextures`로 읽는다. 원본 RGBA·프레임 크기·pivot·동작을 유지한다. 수직 인물판은 수평 yaw만 돌리고 카메라 pitch가 만드는 투영 압축만 scale로 보정하여 지면과 교차하지 않게 한다.

## 실제 합성 구조

정적인 건축·질감·그림자를 [RenderTarget](https://threejs.org/docs/pages/RenderTarget.html)의 색 이미지와 [DepthTexture](https://threejs.org/docs/pages/DepthTexture.html)에 한 번 렌더한다. 매 프레임 화면 사각형에 색 이미지를 그리면서 깊이도 `gl_FragDepth`로 복원하고, 그 위에 인물·접지 그림자·물결·화덕·연기만 렌더한다. 따라서 지붕과 벽 뒤 인물은 캐시된 깊이에 가려진다. 장면 전체를 매 프레임 다시 그린 뒤 픽셀 필터를 붙이는 방식은 아니다.

배경은 첫 로딩·복구 전후·조망 변경·화면 크기 변경 때 다시 만들어진다. 정지 중에는 인물 위치·효과 시간·물결·시설 반응 시간도 멈춘다. `window.villageStyleDiorama.diagnostics`의 `backgroundRenders`/`backgroundRevision`과 `frameCount`/`elapsed`로 확인할 수 있다. 배경은 CSS 화면 크기에 최대 DPR 1.5를 적용하며 저해상도 픽셀화를 주효과로 쓰지 않는다. 캐시는 성능 개선 실험의 기반이며 측정 없이 속도 향상을 주장하지 않는다.

화덕 빛은 동적 투명 지면·벽면 색 합성으로 표현한다. 주변 정적 모형을 매 프레임 다시 조명 계산하거나 전체 동적 그림자를 만들지는 않는다. 자체 3D 프리렌더 실험이므로 실물 모형 사진의 세밀함과 같다고 주장하지 않는다.

## 조작과 수명

WASD/방향키는 화면 방향으로 이동한다. 클릭·터치는 높이 연결과 충돌 판정을 이용한 격자 경로로 시설에 접근한다. Space 또는 사용 버튼으로 시설을 사용하고, R 복구·M 조망·Esc 정지를 사용한다. 입구로 버튼은 위치를 입구에 돌려놓는다.

`?embed=1`에서는 설명만 숨기고 모든 조작 버튼을 보존한다. 처음 로딩할 때 키보드 focus를 가져가지 않으며 캔버스/버튼을 누르면 조작할 수 있다. `resource-scene-dispose`와 `pagehide`에서 RAF·입력 이벤트·텍스처·렌더타깃·메시·그림자·WebGL 문맥을 정리한다.

## 검증 기록

핵심 규칙 테스트는 계단/단상 높이, 건물/화덕/수로 충돌, 두 다리와 짧은 경로, 세 시설 순환, 복구 소품 아래 플레이어 재배치를 다룬다. 실제 Chrome에서 PC 키보드/포인터 순환, 발 접지, 건물 뒤 가림, 복구/조망/resize 배경 갱신, 불씨 효과와 정지, 1100×620/390×620 iframe, DPR 2 터치 입력과 종료를 확인했다. Chrome 오류는 없었고 핵심 규칙 테스트 5개가 통과했다. 모바일 크기와 터치 emulation은 실제 휴대폰 검증으로 간주하지 않는다.
