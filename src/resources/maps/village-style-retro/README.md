# 오래된 나루 · 레트로 3D 마을

목재시장과 낮은 물길, 돌단상 위 작은 도장을 걷는 독립 마을 시안. 큰 3D 건축의 벽·지붕·목재에 직접 그린 작은 픽셀 재질을 붙인다. 기존 자연 3D의 녹색 지형·구형 수관과 다르게, 거친 도시 골목·사선 기와·옅은 안개와 나루의 부피를 중심으로 구성했다.

## 제작과 출처

- 2026-10-13: `pixel-textures.ts`에서 벽·목재·돌·기와·천·간판·물의 32×32 Canvas 그림을 직접 작성. 외부 게임 모델·이미지를 복사하거나 다운로드하지 않았다.
- [Crow Country 개발자 인터뷰](https://blog.playstation.com/2024/05/02/crow-country-retro-original-playstation-era-gameplay-stylings-meet-modern-horror/)는 PS1 시대 표현이 상상할 여지를 남긴다는 설명의 참고 자료다. 원작은 공포 놀이공원이며 이 시안의 마을·색·배치·시설은 별도 제안이다. 원작의 내부 셰이더 구현을 확인했다는 뜻은 아니다.
- [Three.js 텍스처 문서](https://threejs.org/manual/pages/textures.html): 확대는 `NearestFilter`, 원경 축소는 `NearestMipmapLinearFilter`로 구분했다. 낮은 내부 렌더 해상도를 CSS에서 정수 픽셀처럼 확대하며, 카메라 흔들림·강제 왜곡은 넣지 않았다.
- [Three.js 빌보드 문서](https://threejs.org/manual/pages/billboards.html), [투명 재질 문서](https://threejs.org/manual/pages/transparency.html): 간판·창문은 건물에 고정하고, 인물판은 yaw만 카메라로 향하게 한다. 인물을 카메라 pitch로 눕혀 건축과 교차시키지 않는다.
- 승인된 `ai/tiger-hero`의 원본 프레임을 기존 `TrailSprite`·`SpriteTextures`로 재사용한다. 원본 폭·높이·pivot·RGBA를 유지하고, 프레임 pivot을 발 기준으로 삼으며 세로 투영을 보정했다. 별도 아타호 그림이나 유료 생성은 없다.
- 이전 마을 시안의 경로 탐색·입력 수명 패턴을 참고해 이 시안 안에 보행 상태를 둔다. 기존 게임·공용 소스·리소스 목록은 수정하지 않는다.

## 공간과 조작

입구 → 불씨 공방 → 돌계단 도장 → 뱃사공 쉼터 → 귀환. 시장을 따라 남쪽 다리로 바로 갈 수 있고, 도장 동쪽 계단과 북쪽 다리를 경유하는 순환길도 있다. 지면·돌계단·다리 높이를 한 함수가 소유하며 클릭 역투영과 발 위치, 경로 높이 판정에 함께 사용한다.

WASD/방향키는 화면 방향 보행, 클릭·터치는 벽과 물을 우회하는 경로 이동, Space 또는 시설 사용 버튼은 근처 장소 반응이다. R은 도장 차양·목인·등불의 복구 비교, M은 전체 조망으로 좁은 화면 밖의 목적지도 선택할 수 있게 하며, Esc는 이동과 환경 애니메이션·시설 시간 정지, 입구로 버튼은 위치만 되돌린다. 복구로 새 목인이 발 아래 생기면 같은 높이의 빈 곳으로 옮겨 계속 움직일 수 있다.

`?embed=1`은 설명만 숨기고 네 조작 버튼과 사용 버튼을 유지한다. 처음 열 때 부모 라이브러리의 초점을 가져오지 않는다. `resource-scene-dispose`와 `pagehide`에서 입력·RAF·GPU 자원을 정리한다. `window.villageStyleRetro`는 읽기 전용 진단 스냅샷과 canvas 내부 좌표 투영을 제공한다.

## 검증 기록

- `npm run check`, `npm run build`와 당시 로직 검사 6개가 통과했다. 두 다리 접근·단상 옆면 차단·남쪽 계단·시설 순환·복구 아래 탈출·잘못된 입력을 확인했다.
- 실제 설치된 Chrome: 화면 방향 키보드 입력, 공방→도장→쉼터→입구 포인터 순환, 건물 정면 충돌과 뒤편 완전 가림, 키보드로 남쪽 계단 상승(발 1.1, 인물판 1.135), 다리 접지(발 0.4, 인물판 0.435), 화덕 벽면 빛·불꽃·연기·12초 시간, 차양·목인·등불 복구를 확인했다.
- 390 CSS px·DPR 2: 세 시설 방문·복구·전체 조망을 통한 입구 귀환을 실제 터치 이벤트로 완료했다. 화면 밖 목적지는 전체 조망에서 선택할 수 있다.
- 1100/390×620 iframe: 조작 버튼 유지·부모 초점 유지·키보드/포인터 입력·복구/입구/조망·가로 overflow 없음. pause 중 스냅샷과 실제 Canvas PNG가 동일했고, 종료 이벤트 후 `disposed=true`와 RAF 렌더 수 정지를 확인했다. 브라우저 예외 0건.
  390 CSS px·DPR 2와 1100/390×620 iframe은 브라우저 에뮬레이션이며 실제 휴대폰 검증은 아니다. 이 시안은 게임의 경제·저장·전투나 장기 재미를 검증하는 완성 마을이 아니다.
