# 네 지역의 이동길과 심리스 이어걷기

리소스 라이브러리 **맵·마을 → 지역 이동맵**에서 각 지역의 이동길 A/B와 넓은 심리스 탐험맵을 직접 걷는다. 기존 여덟 지도는 개별 비교로 유지하며 `/src/resources/maps/regional-trails/?region=boar|bear|armadillo|mantis`에서 연다. `route=alternate`는 추가 이동길이고, `route=seamless`는 각 지역의 넓은 이어걷기 필드다. 기존 전장과 추가 전장은 오른쪽 링크와 전투맵 비교 갤러리에서 연다.

| 지역        | 이동길 A      | 이동길 B          |
| ----------- | ------------- | ----------------- |
| 솔바람 산길 | 솔바람 옛짐길 | 솔바람 계곡산책로 |
| 백서리 고개 | 백서리 순례길 | 백서리 바람능선   |
| 잿불협곡    | 잿불 운반로   | 잿불 흑요석채석장 |
| 바람대숲    | 바람대숲 샛길 | 바람대숲 물가정원 |

## 네 지역의 넓은 탐험맵

확장된 대숲을 기준으로 지역마다 비슷한 탐험 규모와 인게임 인물 배율을 유지하되, 길의 모양과 풍경이 달라지도록 구성했다. 모두 아타호 v2를 사용하며 명소 방문, 구역 표시, 인게임 시야·전체 지도 전환과 기존 전투맵 A/B 링크를 제공한다. 새 퀘스트·보상·전투 규칙을 추가한 것은 아니다.

| 지역     | 이어걷기 필드                                                                                                | 풍경과 선택 동선                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 솔바람   | [계곡 이어걷기](http://127.0.0.1:8000/src/resources/maps/regional-trails/?region=boar&route=seamless)        | 소나무 숲·석교·물레방아·벌목터·바위고개, 물굽이 우회와 귀환 샛길       |
| 백서리   | [능선 이어걷기](http://127.0.0.1:8000/src/resources/maps/regional-trails/?region=bear&route=seamless)        | 설송림·계류석교·산장·돌탑·빙호, 눈 능선과 낮은 골짜기 선택             |
| 잿불     | [채석장 이어걷기](http://127.0.0.1:8000/src/resources/maps/regional-trails/?region=armadillo&route=seamless) | 옛 운반로·역참 잔해·용암 균열·흑요석채석장, 작업 구역과 둘레 능선 선택 |
| 바람대숲 | [대숲 이어걷기](http://127.0.0.1:8000/src/resources/maps/regional-trails/?region=mantis&route=seamless)      | 깊은 대숲·목교·사당·연못·수련문 앞뜰, 사당 우회와 징검길·먼 물가 선택  |

라이브러리 ID는 `local/regional-trail-지역ID-seamless`다. 기존 A/B 여덟 지도와 함께 지역당 세 가지 배치를 비교할 수 있으며, 이어걷기에서 지역을 바꿔도 같은 보기 모드를 유지한다.

## 바람대숲 이어걷기

[바람대숲 이어걷기](http://127.0.0.1:8000/src/resources/maps/regional-trails/?region=mantis&route=seamless)는 남쪽 입구에서 깊은 대숲의 굽이를 지나 개울·물가정원·북쪽 수련문 앞뜰로 이어지는 보행 샘플이다. 인물·건물 배율과 길 폭을 유지하면서 구역 사이의 거리와 굽이를 확장해 풍경을 순서대로 만난다. 같은 필드와 카메라 안에서 아타호 v2의 위치와 방문 표식을 이어간다.

목교 너머에서는 사당 뒤쪽 대숲을 도는 우회로와 물가정원으로 바로 이어지는 가로샛길을 고른다. 정자에서는 연못 가운데 징검길과 먼 물가를 선택해 같은 수련문 앞뜰로 향한다. 돌아올 때도 가로샛길로 사당 굽이를 줄일 수 있다.

명소 버튼으로 바람 우는 대숲·개울 목교·대숲 작은 사당·대숲 가로샛길·연못 물가정자·연못 징검길·연못 먼 물가·수련문 앞뜰·공통 수련문의 아홉 곳을 찾아가고 가까이에서 살펴본다. 기존 샛길 A와 물가정원 B는 각각의 배치와 표현을 비교하는 별도 항목으로 유지한다.

라이브러리 ID는 `local/regional-trail-mantis-seamless`다. 대숲의 이동길 선택에서 연결 샘플을 고르거나 위 주소로 연다.

## 카메라 보기

기본 `인게임 시야`는 본게임의 `rpgCameraBounds`·`rpgView`·`clearingCameraPose`를 공유한다. 16:10 화면에서 64px 대기 프레임이 화면 높이의 11%를 차지하고 아타호를 따라간다. `지도 전체`는 기존 고정 조망으로 길의 구조와 명소 배치를 비교한다. 보기만 바꿀 때 위치·방문·모션은 유지되고 URL의 `view=game|overview`에 반영된다.

## 조작

- 방향키·WASD로 직접 걷고 길을 누르면 갈 수 있는 길을 따라 걷는다. 바위·물·수풀은 통과하지 않는다.
- 오른쪽 명소 이름은 실제 보행 경로로 이동하는 버튼이다. 명소 가까이에서 Space 또는 살펴보기를 누르면 주변 설명과 방문 표식을 남긴다.
- M은 길 윤곽 표시, Esc는 멈춤·재개, R은 시작점 복귀다. 탭을 벗어나면 누른 입력과 클릭 이동을 멈춘다.
- 길 끝의 전투 입구와 오른쪽 A/B 링크에서 같은 지역의 보스전을 비교한다. 전투는 별도 화면에서 열며 이동맵에 새 전투 판정을 만들지 않는다.

## 구성과 책임

`route-layouts.ts`·`route-alternate.ts`는 지역별 길의 큰 흐름과 명소·모형 배치를 정의한다. `TrailGround`가 이 영역을 부드럽게 이어 작은 비대칭 굴곡을 더하며 보행 윤곽·물가·지면·발 높이를 함께 계산한다. 길 밖은 완만하게 솟고 물가로 낮아지며, 실제 다리와 징검돌 위에서는 디딤면 높이를 사용한다. 격자 경로는 곡선 경계 사이의 구간도 확인한다.

`regional-journeys.ts`가 네 지역의 정의·지표면·구역 이름·화면 안내를 연결한다. `pine-journey-layout.ts`, `frost-journey-layout.ts`, `ember-journey-layout.ts`와 `bamboo-journey-layout.ts`는 각 탐험맵의 폭을 가진 경로·명소 주변 공간·지표면·미술 배치 기준점·구역 이름을 소유한다. 각 `*-journey-scenery.ts`는 해당 지역의 모형과 식생을 같은 지면 위에 배치하고 물과 바닥을 중복 생성하지 않는다. 연결 샘플도 기존 `TrailGround`·`TrailVisit`·`TrailScene`·`TrailScreen`으로 보행과 카메라·방문 상태를 이어가며, 별도 전투 규칙이나 세계 분할·청크 로딩을 추가하지 않는다.

`TrailVisit`은 위치·방향·경로·방문 상태, `TrailTerrain`은 거리장으로 만든 지면·물·길 윤곽과 손칠 질감, `NaturalScenery`는 굽은 수목·잎 군집·층바위와 재질을 맡는다. `trail-backdrop.ts`는 인게임 시야의 바깥 풍경을 잇고, `TrailDressing`은 기존 픽셀 소품과 장식 박자를 소유한다. `TrailScene`은 카메라·인물 합성과 GPU 수명을, `TrailScreen`은 입력·DOM·루프·종료를 조율한다.

HD-2D의 픽셀 인물과 입체 풍경, 디오라마의 낮은 지면 굴곡·재질·그림자, 모형의 비대칭 형태와 손칠 얼룩을 조합했다. 풀·이끼·마른 잎·버섯·재·현무암 조각은 기존 PixelLab 리소스를 낮은 밀도로 섞는다. 솔숲·설원·화산 채석장·물가 대숲의 식생과 색을 구분하고, 목재 장치·지붕·돌 구조물도 함께 다듬었다. 전체 장면은 실시간 3D로 그리며 별도 사진 콜라주나 프리렌더 배경 이미지를 새로 만들지는 않는다.

아타호는 `ai/ataho-v2`의 8방향 대기·`walking-3` 6프레임 보행 원본만 사용한다. 대기64px·보행96px 캔버스는 실제 몸 크기가 같으므로 모두32 pixelsPerUnit을 사용하고 발 피벗과 카메라 투영 보정을 유지한다. 잎·물레방아·눈과 재 등의 작은 장식만 12fps 박자로 갱신하고 보행 입력과 카메라는 연속 시간으로 처리한다. 움직인 장식의 그림자도 같은 박자에 갱신한다.

`#trail`의 `data-region`, `data-variant`, `data-zone`, `data-view`, `data-asset`, `data-facing`, `data-ready`, `data-x`, `data-z`, `data-moving`, `data-remaining`, `data-nearby`, `data-visited`, `data-paused`로 현재 상태를 관찰할 수 있다. Canvas의 `data-motion`·`data-frame`으로 인물 모션을, `data-model-frame`으로 장식의 12fps 진행을 확인한다. 명소 버튼과 입구 복귀로 필요한 경로를 다시 확인한다. 페이지 종료와 라이브러리 선택 해제에서 RAF·이벤트·ResizeObserver·지형·인물 텍스처·WebGL 자원을 정리한다.

본게임 저장·보상·전투 규칙에는 연결하지 않는다. 외부 모델·새 패키지·유료 생성·음향 없이 지역별 모형과 길을 제작했다. `preview-*.jpg`는 실제 이동맵 렌더 캡처다.
