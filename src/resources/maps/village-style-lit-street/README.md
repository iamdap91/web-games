# 등불 아래 거리

옆길 마을의 횡스크롤 패럴랙스, 열린 집들의 실내 단면, 불빛 골목의 높이장 조명을 새 답사 거리로 조합한다. 본게임·경제·전투·영구 저장과 연결하지 않는다.

- 공방(7, 0): Space 입장 → Space 풀무 작업. 12초 동안 화덕·연기·주민 작업·벽돌 불빛이 반응한다.
- 도장(17.5, 0): Space 입장 → Space 수리 → Space 수련. 수리가 지붕·외벽·마루를 바꾸며, 수련 중 등불과 주민 팔이 움직인다.
- 여관(30, 1): 바깥 계단의 아래(23, 0)와 위(26, 1)를 거쳐 2층 찻방으로 이동한다. Space 입장 → Space 차. 아래층 객실과 위층 찻방의 단면이 다르다.
- 입구로: 방문·작업·수리·수련·차 기록을 유지한다. 실행 중에만 남는 시안 상태다.

좌우 또는 A/D로 걷고, 계단 끝에서 위아래 또는 W/S로 층을 바꾼다. 클릭 경로와 시설 바로가기 버튼도 같은 연결을 따른다. 경사 중에는 층을 순간 변경하거나 계단 밖으로 걸을 수 없다. 문 앞에 다가가면 외벽이 옅어지고, 들어가면 내부 골조와 주민 작업이 열린다. 시설 문에서 걸어 멀어지면 나온다.

`LitStreet`가 보행·반응을 소유하고 `LitStreetDrawing`이 변환·표면·애니메이션을 소유한다. 원본 아타호 좌우 프레임은 등록된 RGBA·비율·pivot·재생 시간으로 표시하고 재색칠하지 않는다. 주민은 직접 그린 생활 실루엣이다.

`LitSurface`는 색과 높이장을 별도로 기록하며, 불빛 골목의 순수 normal 함수로 중앙차분 normal을 만든다. 램프의 위치와 표면 normal의 내적, 거리 감쇠, 따뜻한 빛 색을 각 픽셀에 적용한다. 등불 방향 바꾸기로 벽돌·마루·기와 양쪽 모서리의 명암이 바뀐다. 광원이 만드는 투영 그림자나 실제 3D 표면은 계산하지 않는다. 0.12초마다 재질을 갱신하고 불·주민·보행은 화면 프레임마다 움직인다.

정지는 시간·보행·불·빛·캐릭터 모션을 함께 고정한다. 정지 중 resize와 전체 보기, PNG는 고정된 시각을 다시 그린다. embed에서도 모든 조작 버튼을 표시하며 초기 focus를 가져오지 않는다. pagehide와 resource-scene-dispose는 RAF·입력·ResizeObserver·표면 메모리를 정리한다. GPU 자원을 생성하지 않는다.

읽기 전용 `window.villageStyleLitStreet`: ready, snapshot, paused, overview, disposed, project({x,z}), screenPositions, diagnostics(layer/camera/light/normal/inside/floor). 진단으로 게임 상태를 변경할 수 없다.

검증: `npm run check`, `npm run build`. 실제 입력·렌더링은 담당 세션의 브라우저에서 확인한다.

## 통합 화면 검토 · 2026-10-13

통합 담당의 실제 내장 브라우저에서 공방 입장·풀무 → 도장 입장·수리·수련 → 바깥 계단 경로로 2층 여관 → 차의 세 시설 답사를 확인했다. 공방/수리/수련/차 기록과 inside=inn/floor=1이 실제 입력으로 바뀌었다. 다른 카메라 위치에서 전후경 offset이 서로 다른 비율로 움직였고, 등불 방향과 표면 조명 진단도 바뀌었다. 정지 중 실제 Canvas PNG와 상태는 같았으며 390×620에서도 아타호·실내·전체 조작 버튼과 기록을 보존했다. 입구 복귀는 네 행동과 방문 기록을 남긴다. 화면 초기에는 포커스를 가져오지 않으며 실제 버튼 조작 뒤 게임 Canvas에 포커스를 연결했다. 종료는 ready=false와 disposed=true를 함께 표시한다. 좁은 화면 검사는 데스크톱 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다.

## 생활 연결과 읽기 개선

공방 작업으로 구리 경첩을 받아야 도장을 수리할 수 있고, 도장을 수리한 뒤 수련을 마쳐야 여관의 오늘 차를 받는다. 순서를 건너뛰어 시설을 사용하면 필요한 생활 작업을 안내한다. 대화뿐 아니라 경첩·새 마루·수련 주민·찻잔이 같은 진행을 표시한다.

주민은 창빛 마을과 동일한 직접 그린 24px 몸통 폭·43px 높이의 픽셀 자세를 재사용한다. 발 pivot·접지 그림자·nearest·세이지와 청회색 옷을 맞춰 아타호와 함께 읽히게 한다. 아타호 프레임은 변경하지 않는다.

공방의 큰 외벽은 무늬를 줄이고 낮은 벽돌과 화덕 주변에 요철을 모은다. 도장은 넓은 벽/마루와 낮고 긴 처마, 여관은 두 층과 정면 지붕 창으로 실루엣을 구분한다. 전경 관목을 발밑 길 아래로 낮추고 경사 중인 발판을 밝게 보여 실제 계단 경로를 읽게 한다.

## 확장 조합 통합 검토 · 2026-10-13

공방 경첩→도장 수리/수련→경사 계단을 통한 2층 여관→차를 실제 조작해 worked/repaired/trained/tea와 inside=inn/floor=1을 확인했다. 조명 방향 전환, 서로 다른 전후경 offset, 직접 작성 픽셀 주민과 긴 도장 처마/여관 지붕 창을 확인했다. 정지 snapshot/Canvas PNG 동일, 390×620 실내·버튼·가로폭 보존, 입구 복귀의 기록 보존과 종료 disposed=true를 확인했다. 당시 로직 검사 6개가 통과했다.

화면 크기 검사는 데스크톱 내장 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다. 대표 이미지는 통합 환경의 실제 렌더이며 PNG 크기·SHA256은 resources/manifest.json에 기록했다.
