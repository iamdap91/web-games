# 빛바랜 광장 · 회화풍 마을

청회색 바닥에 주황·장미색 석회벽과 먹그림자를 조합한 독립 마을 시안이다. 단순 도형 위에 점 노이즈를 얹는 대신 큰 밝은 광장과 어두운 처마 면을 먼저 배치하고 재질에 따라 지붕의 가로 붓결, 벽의 비스듬한 마른 붓터치, 석회의 큰 얼룩을 겹친다. 코드 그림으로 회화풍 공간을 비교하는 시안이며, 사람 손으로 완성한 회화 원화 수준의 결과를 전제하지 않는다.

## 공간과 조작

- 입구 → 광장 화덕 → 북쪽 도장 → 동쪽 갈대 연못 쉼터 → 입구로 순환한다.
- 도장 뒤 좁은 골목과 연못 바깥 큰길로 우회할 수 있다. 건물과 연못, 낮은 담, 화덕의 발밑 경계를 그림과 세계 좌표에 맞췄다.
- WASD / 방향키로 걷고, 그림의 바닥을 클릭·터치하면 장애물을 우회하는 경로를 찾는다. Space 또는 살펴보기 버튼으로 근처 시설을 사용한다.
- 화덕에 장작을 넣으면 9초 동안 큰 불꽃과 연기, 주황빛 바닥을 볼 수 있다. 도장 복구 시 지붕과 문, 깃발·홍등, 마당의 차 상이 바뀐다.
- 전체 조망 / 가까이 걷기, 잠시 멈춤, 입구 복귀를 제공한다. 멈춤은 이동·시설 시간·물결·연기·빨래를 함께 멈추며 복구·입구 복귀 입력도 실행하지 않는다.
- `?embed=1`은 설명만 숨기고 모든 조작 버튼을 유지한다. 초기 자동 포커스는 없고 Canvas를 누를 때만 포커스를 옮긴다.

## 표현과 출처

시각 참고: [Disco Elysium 공식 미디어](https://discoelysium.com/media). 큰 색면과 낡은 생활 흔적을 비교한 참고 자료다. 해당 게임의 내부 렌더링·자산 제작 방식이라고 주장하지 않는다. 원작 이미지나 음악은 복사·다운로드하지 않았다.

우리의 적용 방식은 다음과 같다.

- 배경·건물의 색면과 방향성 붓터치를 런타임의 메모리 Canvas에 먼저 그린다. 프리렌더 파일이나 추가 외부 이미지는 저장하지 않는다.
- 인물·건물·빨래·낮은 담·나무는 발 위치를 같은 투영 깊이로 정렬한다. 인물이 도장 뒤를 지날 때 지붕과 벽이 인물을 가린다. 원근 카메라 회전이나 3D 표면 투사는 사용하지 않는다.
- 바닥의 화덕 빛은 해당 위치에 합성하는 색 워시다. 실제 3D 동적 조명이 아니다.
- 아타호는 `resources/manifest.json`의 승인된 `ai/tiger-hero` 대기·보행 프레임만 읽는다. `width`, `height`, `pivot.x`, 밑변 기준 `pivot.y`를 사용해 원래 비율과 발 기준을 유지한다. 픽셀 프레임을 다시 생성하거나 변형하지 않는다.
- `village.ts`는 보행·반경 충돌·격자 경로·시설 반응을 소유한다. `drawing.ts`는 그림과 좌표 변환, `index.ts`는 DOM·입력·수명을 연결한다.
- 공개 진단 객체 `window.villageStylePainted`는 읽기 전용 `ready`, `snapshot`, `paused`, `overview`, `disposed`, `screenPositions`, `project(point)`를 제공한다. `screenPositions`는 Canvas 내부 CSS 좌표다.
- `resource-scene-dispose` / `pagehide`에서 RAF·입력·ResizeObserver·이미지 참조와 배경 레이어를 정리한다.

추가 패키지·유료 서비스·새 캐릭터 그림을 사용하지 않았다. 본게임 진행·저장·전투는 연결하지 않는다. 그림의 자유로운 붓 가장자리와 충돌의 정확한 경계가 아주 작게 어긋날 수 있어, 시설과 건물 발밑의 큰 기준선을 우선한다.

## 검증

`npm run check`, `npm run build`로 타입·린트·형식과 빌드 상태를 확인한다. 실제 보행 경로·대체 순환로·장애물·화덕 시간·복귀의 상태 보존은 브라우저 조작으로 확인한다. 설치된 Chrome의 실제 Canvas에서 키보드 이동과 포인터 시설 순환, 복구 전후, 멈춤, 도장 뒤 가림을 확인한다. 1100 / 390 CSS 폭 × 620 높이 iframe의 조작 버튼·부모 포커스·입력 정리와 390 CSS 폭 / DPR 2 터치 에뮬레이션도 별도로 확인한다. 에뮬레이션은 실제 휴대전화 검증을 의미하지 않는다.

제작 파일은 `src/resources/maps/village-style-painted/`에 한정한다. 라이브러리 등록과 실제 화면 썸네일은 통합 담당자가 관리한다.
