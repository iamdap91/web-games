# 색돌이 마을 · 선화와 색칠책

흰 골목에서 도장 복구를 누르면 색이 도장을 중심으로 퍼진다. 큰 크림색 여백·굵은 검은 윤곽·둥근 비대칭 문과 창·꽃 얼굴 나무로 기억할 지점을 만들었다. 색 회복 뒤에는 건물·정원·개울의 큰 색면과 화분·빨래·도장 깃발·마당 놀이가 돌아온다.

## 제작과 참고

- 배경·나무·건물·소품 전체: `drawing.ts`의 Canvas2D 경로·베지어 곡선·색면으로 직접 제작. 외부 그림·모델·AI 생성·새 패키지 없음.
- 아타호: 기존 `ai/tiger-hero` 대기·보행 프레임 재사용. 원본 RGBA와 프레임 width/height/pivot을 유지하고 흑백으로 변환하거나 다시 생성하지 않음.
- 참고: [Chicory 공식 사이트](https://chicorygame.com/). 공식 소개에서 확인한 것은 그림 그리기와 색 회복을 활용한 탐험 방향이다. 공식 이미지 링크·소개를 살펴보고 선화와 제한된 채색의 관계만 참고했다. 원작 내부 렌더링 파이프라인의 재현을 주장하지 않는다.
- 우리 시안의 차이: 자유 페인팅·원작 퍼즐을 만들지 않았다. 마을 복구 전후와 공간 가림·시설 반응을 비교하는 독립 시안이다.
- 그림과 충돌은 `village.ts`의 같은 월드 좌표를 사용하고, 배경 바닥 두 장만 캐시한다. 건물·나무·시설·인물을 발밑 z로 정렬한다. 카메라와 포인터 역변환은 CSS 픽셀을 쓰고, backing store는 최대 DPR 2를 적용한다.
- 화덕 빛: 선화의 마당과 공방 벽에 제한된 살구색을 합성한다. 3D 광원·노멀맵은 사용하지 않는다.

## 조작

`http://127.0.0.1:8206/src/resources/maps/village-style-line/` 또는 리소스 라이브러리에서 연다. WASD·방향키, 길 클릭·터치로 걷고 Space 또는 시설 버튼으로 살펴본다. 클릭 이동은 건물과 물을 우회한다. 입구 → 화덕공방 → 도장 → 아래 다리 → 동그란 정원 → 위 다리 → 귀환을 걸을 수 있으며, 같은 길로 돌아가는 짧은 선택도 가능하다.

색 돌려주기/선화로 보기·전체 조망/가까이 걷기·잠시 멈춤·입구로 버튼을 제공한다. pause 중에는 입력·보행·불·연기·빨래·색 회복 시간이 모두 멈춘다. 입구로 버튼은 색과 방문 기록을 유지한다. iframe 설명은 숨겨도 모든 조작 버튼을 보존하고 초기 키보드 포커스를 강탈하지 않는다.

## 검증 기록

규칙 테스트 5개가 물·건물·나무·화덕 충돌, 두 다리의 순환, 경로 우회와 도달, 정규화 속도, 큰 시간 제한, 시설 근접과 색 회복/되돌리기를 확인했고 모두 통과했다. `npm run check`와 `npm run build`도 통과했다. 실제 설치된 Chrome에서 렌더와 키보드·포인터 이동, 건물 뒤 부분 가림, 화덕 반응, 선화↔채색, pause, iframe 1100/390 CSS 폭 × 620 높이, DPR 2 터치 입력과 정리 이벤트를 확인했다. PC에서는 140단위 이상을 이동해 두 다리와 세 시설을 순환했고, 390 폭 iframe에서도 터치로 같은 순환을 완주했다. 키보드 직진은 도장 앞 z=-5.59 근처에서 차단됐다. 호스트 버튼의 초기 포커스와 조작 버튼 노출을 확인하고, 정리 뒤 이미지와 바닥 캐시 수가 0으로 줄고 시간이 멈추는 것도 확인했다. CSS 폭·터치 에뮬레이션은 실제 휴대전화 검증을 의미하지 않는다.

읽기 전용 `window.villageStyleLine`은 ready, snapshot, paused, overview, disposed, diagnostics, 시설별 screenPositions와 project(point)를 제공한다. `resource-scene-dispose`/pagehide 때 RAF·입력·ResizeObserver·그림 캐시를 해제한다. 본게임 진행·저장·전투와 분리된 프로토타입이며, 재미와 세계관의 최종 채택 여부는 별도 플레이 평가가 필요하다.

검증 캡처: 선화 전 `/private/tmp/line-initial.png`, 채색 후 `/private/tmp/line-colored.png`, 화덕 `/private/tmp/line-hearth.png`, 뒤 가림 `/private/tmp/line-behind.png`, 좁은 iframe `/private/tmp/line-iframe-390-620.png`, 터치 순환 완료 `/private/tmp/line-mobile-loop.png`. 라이브러리 썸네일은 통합 담당자가 실제 라이브러리 안에서 별도로 캡처한다.
