# 창빛 이어지는 마을

개울 골목의 탑다운 픽셀 구성, 불빛 골목의 색·높이장 normal 조명, 열린 집들의 내부 생활을 새 독립 마을로 조합한다. 횡스크롤 거리와 다른 시점이며 본게임·경제·전투·영구 저장에 연결하지 않는다.

공방·수련당·찻집의 바닥과 가구와 주민은 밖과 안 모두 동일한 월드 좌표·상태·그리기 함수를 사용한다. 밖에서는 지붕과 벽의 두 창 구멍을 통해 생활이 보이고, 문을 실제 걸어 통과하면 지붕이 옅어져 단면을 볼 수 있다. 실내와 실외 사이의 다른 장면으로 순간이동하지 않는다. 창 밖으로 보이는 불·주민·찻잔은 실내에서도 같은 시간에 움직인다.

답사 순서:

1. 공방 문(-7, 0.8) → Space → 실내 시설로 → Space. 풀무(-8.5, -2.5)를 도우면 불이 14초 살아나며 수련당 열쇠를 받는다.
2. 문으로 나가기 → 수련당 문(0, -6.2) → Space → 실내 시설로 → Space. 마루(0, -9.5)를 복구하면 창·지붕·마루와 창빛이 바뀌고 찻집 문이 열린다. Space를 한 번 더 눌러 수련한다.
3. 문으로 나가기 → 찻집 문(9, -1.2). 개울 다리(4.5, 5)를 돌아 건넌다. Space → 실내 시설로 → Space. 찻상(9, -4.5)에서 차를 받는다.
4. 문으로 나가기 또는 입구로. 작업·열쇠·복구·수련·차·방문 기록은 유지된다.

모든 길찾기는 반 단위 격자로 벽·문 폭·다리의 실제 충돌을 공유한다. 잠긴 건물 안 클릭이나 다른 방으로 이동은 거절하고 문 사용을 안내한다. 수동 입력도 같은 판정을 적용한다. 실내 밖으로 나가려면 문을 통과해야 한다.

배경의 기본 픽셀과 주민의 픽셀은 1 단위이며 nearest로 확대한다. 주민은 발 pivot을 갖는 24px 몸통 폭·43px 높이의 직접 그린 세이지/청회색 옷 인물이다. 아타호는 승인 `ai/tiger-hero`의 원본 RGBA·비율·pivot·시간을 보존한다. 색·높이장·중앙차분 normal·램프 내적·거리 감쇠는 기존 독립 거리의 `LitSurface`를 재사용한다. 투영 그림자나 실제 3D 지붕을 계산하지 않는다.

`WindowVillage`가 실내 권한·문 전환·경로·생활 반응과 잠금을 소유한다. 화면은 입력·RAF·resize·그림 수명을 소유한다. 초기 focus를 가져오지 않으며 사용자 버튼·클릭 이후 키보드를 받는다. 정지 중 시간과 보행·빛·생활이 고정된다. 정지 resize와 전체 보기, PNG는 고정된 상태를 다시 그린다. pagehide/resource-scene-dispose는 RAF·이벤트·observer·표면 메모리를 정리한다. GPU 자원을 만들지 않는다.

읽기 전용 `window.villageStyleWindowVillage`: ready, snapshot, paused, overview, disposed, project({x,z}), screenPositions(door/fixture), diagnostics(camera/light/windows/normal/pixel/inside/transition). 진단용 복사본으로 진행을 바꿀 수 없다.

검증: `npm run check`, `npm run build`, `node --test tests/village-style-window-village.test.mjs`. 실제 입력·시각 검토는 담당 root가 통합 환경에서 진행한다.

## 확장 조합 통합 검토 · 2026-10-13

공방 문과 풀무→수련당 문과 복구/수련→개울 다리→찻집 문과 차를 실제 보행해 worked/repaired/trained/tea 및 세 방 방문을 확인했다. 정면 보행 모션명을 원본 move/stand에 맞춘 빌드에서 출입이 계속 진행됐다. 최종 문턱 수정 뒤 수동 S 출구와 D 외부 보행으로 벽 띠 고착이 사라짐을 확인했다. 정지 snapshot/Canvas PNG 동일, 390×620 가로 넘침 없음, 재방문의 기록 보존과 종료 ready=false/disposed=true를 확인했다. 전용 테스트 7개가 통과했다.

화면 크기 검사는 데스크톱 내장 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다. 대표 이미지는 통합 환경의 실제 렌더이며 PNG 크기·SHA256은 resources/manifest.json에 기록했다.
