# 펼쳐지는 책 속 마을 · 종이·모형·조립 조합

종이골목의 얇은 카드·접힌 지붕, 손끝 골목의 12fps 모형 표시, 이어진 골목의 조립 완료 후 실제 길 연결을 조합한 독립 3마당이다. 기존 시안을 iframe으로 감싸거나 색만 바꾼 화면이 아니다. 공방/도장/전망대와 두 접힌 다리, 종이 페이지의 틈을 새 공간으로 구성했다.

## 직접 돌아보기

1. 입구 `(-10, 6.5)`에서 제본 공방 `(-8, 2)`으로 걸어가 사용한다.
2. 2.4초 동안 얇은 공방 벽/측면/지붕과 첫 다리가 펼쳐진다. 조립 중에는 다음 마당 클릭/키보드 통행이 모두 막힌다.
3. 첫 다리 `(-2.5, 0)`를 건너 종이 도장 `(3, 0.8)`을 사용한다.
4. 두 번째 조립이 끝나면 둘째 다리 `(8.5, -3.5)`를 건너 책갈피 전망대 `(14, 0.5)`에 갈 수 있다.
5. 전망대를 사용한 뒤 두 다리를 지나 입구로 귀환하면 한 바퀴 완료를 기록한다.

WASD/방향키는 연속 보행, 화면 클릭/터치는 경로 이동, Space/사용 버튼은 가까운 시설 반응이다. M은 조망, Esc는 정지. 입구로 버튼은 위치만 되돌리고 조립/방문/완료를 유지한다. 버튼이나 처음 로딩으로 embed 부모의 focus를 가져오지 않으며 canvas를 직접 누를 때만 canvas에 focus한다.

## 상태와 표현

- `BookVisit`은 연속 보행, 두 조립 진행률, 조립 완료에 따른 통행, 방문/귀환을 소유한다.
- `canWalkBook`과 `bookRoute`는 같은 페이지/다리/건물 경계를 사용한다. 캐릭터 반경을 포함한 8방향 샘플로 틈과 가장자리를 판정한다. 막힌 다음 장의 클릭은 현재 장의 가장자리로 대체하지 않고 사용 안내를 준다.
- `BookScene`은 페이지 층과 탭, 얇은 전면/측면 카드, 지붕 힌지, 양쪽에서 일어나는 종이 다리를 구성한다. 종이 조립과 흔들리는 종이 나무는 12fps 표시 시간에 맞추지만 입력/보행/아타호 애니메이션은 매 프레임 진행한다.
- 얇은 종이 카드와 인물은 같은 3D 깊이 검사로 가린다. 원본 아타호 RGBA, 비율, 방향 모션, frame-pivot을 유지한다.
- 정지는 조립/장식/보행을 함께 멈추고 resize에서는 동결 상태를 한 번 다시 그린다. pagehide/resource-scene-dispose는 입력·RAF·ResizeObserver·텍스처·기하·재질·shadow·WebGL을 정리한다.

`window.villageStylePopupBook`는 읽기 전용 `ready`, `paused`, `overview`, `disposed`, `snapshot`, `diagnostics`, `project(point)`, `screenPositions`를 제공한다. snapshot은 position/player/access/folds/visited를 포함해 깊은 동결을 적용한다. diagnostics에는 `renderCount`, `modelFrame`, `modelChanges`, `cadence: 12`, 원본 actorWidth/actorHeight/actorPivot, depthTest, disposed가 들어 있다.

## 리소스와 검증

페이지/인쇄/탭/건축/종이 나무는 코드로 직접 작성했다. ai/tiger-hero의 승인된 기존 로컬 프레임만 재사용한다. 새 외부 이미지·다운로드·유료 생성·패키지와 본게임 경제/전투/저장은 포함하지 않는다.

`npm run check`, `npm run build`, `node --test tests/village-style-popup-book.test.mjs`로 두 단계 통행 경계, 접힘 중 키보드 차단, 닫힌 장 클릭 안내, 두 다리 경로와 실제 귀환, 중복 조립 방지/정지, 12fps 표시 안의 연속 보행, 외부 snapshot 변경 방지 7개를 검증했다. 실제 브라우저 입력·조립 모습·DPR/resize/embed/종료는 담당 세션 통합 검토에서 확인한다.

다리는 2.4초 조립 후 통행 가능 상태로 확정된다. 조립을 되감거나 새 자유 건축물을 만드는 규칙은 포함하지 않는다. 작은 화면은 캐릭터를 따라가고 전체 조망에서 책 전체를 볼 수 있다.

## 확장 조합 통합 검토 · 2026-10-13

닫힌 다음 장 클릭은 이동하지 않고 안내했다. 공방→첫 다리→도장→둘째 다리→전망대를 실제로 걸어 사용했고 각각 조립 완료 뒤에만 access가 열렸다. 조립 초반 정지 snapshot이 고정됐다. 전망대 방문 뒤 순간 입구 복귀는 returned=false였고 두 다리를 실제로 걸어 돌아오면 true였다. 390×620 상태·가로폭 보존과 종료 disposed=true를 확인했다. 순간 복귀 회귀 테스트를 포함해 전용 8개가 통과했다.

화면 크기 검사는 데스크톱 내장 브라우저 뷰포트 검사이며 실제 휴대전화 검증은 아니다. 대표 이미지는 통합 환경의 실제 렌더이며 PNG 크기·SHA256은 resources/manifest.json에 기록했다.
