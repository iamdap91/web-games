# 동글 집 안팎 · 기능 전이

A 맵: **동글 언덕의 장난감형**. B 기능: **창빛 마을의 실내외 동일 월드 생활**.

## 제작 원리와 기존 시안의 차이

돔 지붕·파스텔·둥근 지형을 유지하고 중앙 도장을 실제 벽·창 구멍·문·가구로 분해했다. 별도 실내 장면 없이 같은 주민과 주전자가 창을 통해 보이고 문으로 들어가면 앞벽과 돔만 걷힌다. 주민은 창빛 마을의 자체 픽셀 주민이며 원본 아타호와 구분된다.

원본 폴더를 변경하지 않은 독립 시안이다. 환경은 Three.js 자체 제작이며 승인된 아타호 RGBA 프레임의 방향·비율·발 pivot을 사용한다. 기능의 이동·충돌·발견 상태는 Visit 객체가 소유하며 화면은 입력·렌더·수명만 연결한다.

## 조작과 확인 좌표

문 (0,-3.3) → 실내 (0,-4.8). 중앙 우물을 우회하는 클릭 경로를 사용한다. 탁자 (-1.25,-5.25), 뒤 선반 (0,-6.35)은 충돌한다.

WASD / 방향키 보행, 클릭·터치 장애물 우회 이동, Space / 사용 시설 반응, M 전체 조망, R 기존 도장 복구 비교, Esc 일시 정지. 정지 시 입력·생활 애니메이션이 멈추며 재개 후 이어진다. iframe embed 모드에서도 전체 조망·복구·멈춤·입구로·시설 사용 버튼을 유지한다. 소개만 줄이고 키 조작 설명과 상태를 표시하며, 944×538 및 390×620 크기 안에서 화면과 조작부를 배치한다.

## 입구 복귀와 완료 표시

입구로 버튼은 순간 이동이며 방문·복구 기록을 보존한다. 이 시안에는 실제 귀환 보행의 완주·전체 완성 판정이 없다. 시설 방문은 해당 위치에 걸어 도달하고 사용한 별도의 기록이다.

## 검증

`tests/village-style-toy-interior.test.mjs`에서 실제 문·가구 충돌 및 보행 도달과 주민 시간 진행을 검증한다. Chrome 실제 실행으로 클릭 입장/이동, Space, 정지·재개, DPR 2와 세로 화면 리사이즈를 확인한다.

`window.villageStyleToyInterior`는 읽기 전용 화면 조회용 진단이다. `ready`, `snapshot`, `project`, `screenPositions`, `paused`, `disposed`, `diagnostics`를 제공하며 게임 상태를 바꾸는 디버그 명령을 공개하지 않는다. 좌표는 canvas CSS 픽셀 기준이며 페이지의 canvas bounds를 더해 입력한다.

이 시안은 본게임 경제·저장·원정과 연결하지 않는다. 추가 이미지 생성이나 다운로드 없이 기존 승인 캐릭터와 직접 만든 환경을 사용한다.

## 라이브러리 통합 검토 · 2026-10-13

실제 문을 통해 같은 월드의 실내에 도착해 주전자를 사용했다. 주민을 주인공과 다른 픽셀 인물로 표시하고 실내 발 접점을 확인했다.

맵·마을에서 “기능 전이”로 검색한 9개 항목과 원래 맵·기능 출처 연결을 확인했다. 상세 안의 실제 키보드 보행 및 항목 전환 후 이전 뷰어의 disposed=true를 확인했다. 대표 PNG의 크기·SHA256은 resources/manifest.json에 기록한다. 좁은 화면 검증은 데스크톱 브라우저 뷰포트·DPR 에뮬레이션이다.
