# 둥근 길 속 집 · 기능 전이

A 맵: **둥근 길의 곡선 지평선형**. B 기능: **단면 마을의 접근과 입장에 따른 지붕·앞벽 개방**.

## 제작 원리와 기존 시안의 차이

원통 지평선과 원본 마을 건축을 보존하고 먼 길의 집을 실제 빈 실내로 구성했다. 문 앞 접근 시 지붕·앞벽을 걷으며 문으로 보행한다. 벽·가구는 세분된 정점을 원래 월드에서 곡면으로 변환하고 주민·아타호·그림자·클릭도 같은 변환을 따른다. 표시를 평면으로 돌려 비교할 수 있다.

원본 폴더를 변경하지 않은 독립 시안이다. 환경은 Three.js 자체 제작이며 승인된 아타호 RGBA 프레임의 방향·비율·발 pivot을 사용한다. 기능의 이동·충돌·발견 상태는 Visit 객체가 소유하며 화면은 입력·렌더·수명만 연결한다.

## 조작과 확인 좌표

M 전체 조망 → 문 (-6,-17.2) → 집 안 (-6,-18.6) 클릭 → M 따라 걷기. 탁자 (-6.9,-19.4), 옆벽·뒷벽은 충돌한다.

WASD / 방향키 보행, 클릭·터치 장애물 우회 이동, Space / 사용 시설 반응, M 전체 조망, R 기존 도장 복구 비교, Esc 일시 정지. 정지 시 입력·생활 애니메이션이 멈추며 재개 후 이어진다. iframe embed 모드에서도 전체 조망·복구·멈춤·입구로·시설 사용 버튼을 유지한다. 곡선/평면 버튼도 유지한다. 소개만 줄이고 키 조작 설명과 상태를 표시하며, 944×538 및 390×620 크기 안에서 화면과 조작부를 배치한다.

## 입구 복귀와 완료 표시

입구로 버튼은 순간 이동이며 방문·발견·복구 기록을 보존한다. 새 `loopComplete` 판정은 3개 시설 방문 뒤 실제 보행으로 입구 바깥에서 안쪽 경계를 넘을 때만 완료된다. 미완주 상태의 순간 입구 복귀는 완주로 세지 않으며, 이미 얻은 완주와 방문 기록은 보존한다. 순간 복귀 후 다시 바깥으로 나가 걸어서 들어와도 기존 시설을 다시 사용하도록 강제하지 않는다.

## 검증

`tests/village-style-horizon-interior.test.mjs`에서 실제 문·가구 충돌 및 보행 도달과 곡면 역변환, 순간 복귀 미완주·실제 경계 보행 완주·기존 기록 보존을 검증한다. Chrome 실제 실행으로 클릭 입장/이동, Space, 정지·재개, DPR 2와 세로 화면 리사이즈를 확인한다.

`window.villageStyleHorizonInterior`는 읽기 전용 화면 조회용 진단이다. `ready`, `snapshot`, `project`, `screenPositions`, `paused`, `disposed`, `diagnostics`를 제공하며 게임 상태를 바꾸는 디버그 명령을 공개하지 않는다. 좌표는 canvas CSS 픽셀 기준이며 페이지의 canvas bounds를 더해 입력한다.

이 시안은 본게임 경제·저장·원정과 연결하지 않는다. 추가 이미지 생성이나 다운로드 없이 기존 승인 캐릭터와 직접 만든 환경을 사용한다.

## 라이브러리 통합 검토 · 2026-10-13

전체 조망에서 문과 방으로 실제 클릭 보행하고 따라 걷기 시점에서 단면을 확인했다. 발 투영과 클릭 역변환이 같은 곡면을 사용했다.

맵·마을에서 “기능 전이”로 검색한 9개 항목과 원래 맵·기능 출처 연결을 확인했다. 상세 안의 실제 키보드 보행 및 항목 전환 후 이전 뷰어의 disposed=true를 확인했다. 대표 PNG의 크기·SHA256은 resources/manifest.json에 기록한다. 좁은 화면 검증은 데스크톱 브라우저 뷰포트·DPR 에뮬레이션이다.
