# 움직임과 풍경 · 2.5D 표현 비교

실제 게임에 적용하기 전에 원본 그림과 표현의 차이를 살펴보는 독립 리소스 비교장이다. 라이브러리의 **효과 → 표현 비교**에서 찾아 연다. 본게임 진행·피해·보상·저장 객체를 만들지 않는다.

## 비교 기준

- 공격 기준판은 현재 `drivePose()`와 `drawDriveStrikes()`의 회전 강타를 사용한다. 원본 `ai/tiger-hero`의 `turn-kick` 프레임·발 피벗·크기·접촉 시각·행동 길이·히트스톱을 공유한다. 전체 전투의 명령 UI·카메라 줌·오버드라이브 진입은 제외한다.
- 추가 공격판은 같은 프레임의 유지 시간을 다듬고 짧은 발 궤적을 더한다. 접촉·피해 규칙을 새로 계산하지 않는다. 두 항목을 모두 끄면 기준판과 같은 표시 경로를 사용한다.
- 숲은 현재 아트 기준·환경 리소스·도트 아타호를 재사용한 비교용 배치다. 본게임 맵 전체를 복제한 화면은 아니다. 기준판도 입체 배경·인물의 앞뒤 가림을 유지한다.
- 환경 추가판은 잎·천의 늦은 반응, 국소적인 등불과 반딧불, 높은 다리의 위·아래 경로를 비교한다. 세 항목을 끄면 기준판의 상태와 표현으로 돌아간다.
- 카메라·DPR·인물 표시 크기는 양쪽에서 같다. 프로젝트의 원본 픽셀을 재사용하며 신규 이미지 생성·다운로드는 하지 않는다.

## 조작

- 공격: Space 또는 회전 강타 버튼. 반복 재생을 끄면 한 번씩 확인할 수 있다.
- 공격 자세 탐색: 슬라이더를 움직이면 정지한 채 양쪽의 같은 공격 시점을 살펴본다.
- 숲: 방향키나 화면 방향 버튼으로 걷기. 자동 경로 중 방향을 입력하면 직접 보행으로 전환한다.
- 길 선택: 위로 건너기는 높은 빠른 길, 아래로 돌아가기는 다리 밑을 지나 발견 장소로 향한다. 높이 옵션을 끄면 같은 배치의 평지 경로를 비교한다.
- 주변 반응: 숲에서 Space 또는 주변에 충격 버튼.
- 공통: 일시정지 또는 P, 0.25배, 움직임 표시, 처음부터. 모션 감소 환경에서는 흔들림과 잔광을 줄인다.

## 판단할 점

표현이 많아지는 것보다 공격 자세·접촉이 잘 읽히는지, 반복 조작이 즉시 반응하는지, 주변 반응과 길의 선택이 기억에 남는지가 중요하다. 이 시안의 브라우저 실행 검증은 본게임의 재미나 실제 기기 검증을 대신하지 않는다.
