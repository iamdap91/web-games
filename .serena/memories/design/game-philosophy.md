# 게임 기획·개발 철학

사용자가 직접 확인하고 저장을 요청한 원칙이다. 게임 기획·개발 시 다음 원칙을 따른다.

- **재미는 필수 조건이다.** 기능이 작동하거나 콘텐츠가 존재하는 것만으로 완성이라 판단하지 않는다. 플레이어가 실제로 재미를 느끼는지가 최우선 기준이다.
- **구현 편의보다 경험의 가치를 우선한다.** 만들기 쉬운 이벤트로 수량을 채우지 않는다. 적더라도 각각에 놀람, 즐거움, 새로운 경험처럼 기억에 남을 순간이 있어야 한다.
- **플레이어가 직접 겪는 경험을 설계한다.** 단순한 시각적 차이보다 이동·선택·반응과 연결된 사건을 선호한다. 익숙한 행동과 예상을 뒤집어 와우 모먼트를 만든다.
- **플랫폼의 표현 가능성을 적극 활용한다.** 웹게임이라면 캔버스 안에만 한정하지 않고 웹의 기능까지 활용한다. 새로운 경험을 위해 조작 자체를 불필요하게 복잡하게 만들지는 않는다.
- **설명보다 직관과 간결함을 우선한다.** 보고 행동하면 이해할 수 있게 설계한다. 과도한 안내, 감성적인 장문, 성취감을 말로 설명하는 문구를 지양한다.
- **관찰을 숙제로 만들지 않는다.** 미세한 차이를 샅샅이 찾거나 암기하는 부담을 주지 않는다. 놓치기 쉬운 변화는 드물게 사용한다.
- **공정함은 경험의 목적에 맞게 조절한다.** 강한 놀람을 위한 소수의 의도적인 ‘억까’는 허용한다. 다만 대응하는 재미를 의도한 상황에는 실제로 회피하거나 극복할 여지가 있어야 한다.
- **몰입을 깨는 허술함을 최소화한다.** 어색한 동작, 맥락에 맞지 않는 표현, 성의 없어 보이거나 ‘짜친다’고 느낄 요소를 엄격하게 다듬는다.
- **실제 플레이로 판단하고 개선한다.** 사용자의 플레이 피드백을 개발 과정에 적극 반영한다. 기술적 검증과 재미 검증을 구분하고, 재미없는 요소는 제거하거나 재설계한다.
